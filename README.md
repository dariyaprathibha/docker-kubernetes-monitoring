# Docker & Kubernetes Monitoring Project

## What I Built
- Dockerized a sample web application using Dockerfile
- Deployed the app on Kubernetes using Deployment & Service YAML files
- Set up Prometheus for metrics collection
- Visualized CPU, Memory & Pod status in Grafana dashboards

## Tools Used
Docker | Kubernetes | Prometheus | Grafana | YAML | Linux

## Project Structure
- Dockerfile - To containerize the app
- deployment.yaml - To deploy pods in Kubernetes
- service.yaml - To expose the app
- monitoring - Prometheus & Grafana setup
